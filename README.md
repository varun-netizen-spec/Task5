# Decision Trees and Random Forests – Heart Disease Classification

This project demonstrates the use of **tree-based models** (Decision Tree and Random Forest) for **classification** on the heart disease dataset.

## 📌 Objective
To explore Decision Trees and Random Forests using Scikit-learn and visualize the models using tools like `matplotlib`, `seaborn`, and `plot_tree`.

---

## 🧰 Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab (for execution)

---

## 📊 Dataset
- Filename: `heart.csv`
- Features include: age, sex, cp (chest pain), trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal
- Target: `0` = no heart disease, `1` = heart disease

---

## 🚀 Steps Performed

1. **Data Loading** and Splitting
2. **Train Decision Tree Classifier**
3. **Visualize Tree Structure**
4. **Analyze Overfitting by Varying Depth**
5. **Train Random Forest Classifier**
6. **Interpret Feature Importance**
7. **Evaluate using Cross-Validation**

---

## 📈 Results

- Decision Tree: Easy to interpret, but prone to overfitting.
- Random Forest: Higher accuracy and better generalization.
- Cross-Validation: Verified model stability.

---

## 📊 Sample Output
- Decision Tree Depth vs Accuracy Plot
- Tree Visualization using `plot_tree`
- Feature Importance using Bar Plot
- Cross-validation Accuracy Report

---

## 📁 How to Run

1. Upload `heart.csv` in Google Colab.
